# SQL Tasks (Ad-hoc Only)

Папка `sql/tasks` зарезервирована только для одноразовых задач:

- ad-hoc запросы от аналитиков;
- временные backfill/исправления;
- Jira-тикеты формата `DE-1234_*`.

Регулярная автоматизация НЕ хранится в `sql/tasks`.
Постоянные ETL/DV-скрипты вынесены в `sql/pipelines` и запускаются Airflow DAG-ами.
