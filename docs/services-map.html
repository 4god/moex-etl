Интерактивная карта сервисов (Docker Compose)

Узлы можно перетаскивать, колесо мыши — масштаб. Клик по узлу — детали и ссылки. Граф рисуется сразу при открытии страницы. Если открыли карту как http://IP:8765/..., хост в ссылках берётся с этого IP автоматически; при открытии файла с диска по умолчанию — localhost. Поле ниже можно поправить вручную.

Выберите сервис

Кликните узел на графе. Пунктирные рёбра — логические потоки данных; сплошные — зависимости depends_on в compose.
Файл docs/services-map.html — откройте в браузере локально или с VM (например через SFTP/клон репозитория). Профили: --profile bi (Metabase), --profile dbt (контейнер dbt CLI).
